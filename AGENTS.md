# SilksongUnity6 reference project

For research, navigation, or reuse in another game, start at [Docs/AgentReference/README.md](Docs/AgentReference/README.md). It routes tasks to source-backed system chapters and searchable data appendices.

- Reference paths are relative to this repository; distinguish this reference root from a new target game's root.
- Read the relevant section and exact index rows before opening large source/scene files. Do not load the entire reference pack into context.
- Follow C# together with actual scene/Prefab components, external PlayMaker templates, animation events, configuration assets and resource references.
- Treat the current recovered/modified checkout as the evidence source. See `Docs/AgentReference/90_COVERAGE_AND_LIMITS.md` for known gaps and the difference between indexing, semantic tracing and runtime verification.
- Preserve source identity using path, stable symbol, GUID/fileID and content hash. Names alone are not sufficient to identify a scene instance or resource variant.

The reference pack's entry point is a document, with domain chapters and non-executable indexing appendices. Existing user changes and research files remain part of the local evidence; user instructions determine the requested implementation scope.
