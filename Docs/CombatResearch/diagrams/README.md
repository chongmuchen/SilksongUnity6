# Boss 战斗图样稿

三个案例用于确认战斗图的视觉表达方式。它们根据当前 Unity 工程已核对的状态机、动画事件和场景参数绘制，不包含运行录像测量。

|案例|看什么|矢量原稿|预览|
|---|---|---|---|
|苔藓之母|血量如何改变选招；俯冲的五个阶段；一次性高度采样|[SVG](01-moss-mother.svg)|[PNG](01-moss-mother.png)|
|Lace 第一战|半血与距离决策；冲刺时间轴；两刀的开关事件；格挡反击|[SVG](02-lace.svg)|[PNG](02-lace.png)|
|Trobbio|三个选招池；Boss、炸弹、舞台的并行逻辑；计时与位置共同门控|[SVG](03-trobbio.svg)|[PNG](03-trobbio.png)|

SVG 使用基础矢量路径和文本，保留可供 Figma 导入的矢量原稿。`*-geometry.svg` 单独保留几何图形；同名 JSON 保留文字、颜色与位置，可用于重建原生 Figma 文本层。PNG 仅供快速预览。

图中的大节点可能折叠多个原 FSM 状态，不应当成完整实现清单。秒数是游戏时间；动画帧号从 0 起，标称动画时刻不等于录像实测。几何运动图属于示意，只有明确标注的坐标和阈值来自场景。颜色必须结合说明阅读：例如苔藓之母的红色俯冲段突出主要攻击威胁，并不表示其他阶段没有身体接触伤害。

完整复现仍需对照 [AI 复现规格](../丝之歌战斗逻辑_AI复现规格.md)、[人类学习版](../丝之歌战斗逻辑_人类学习版.md) 和 [Boss 原始状态参考](../parts/bosses-state-reference.md)。本批图是这两份文档的视觉入口，不取代参数表、退出清理和全局中断逻辑。

本地制图源：`board_style.py` 与三个 `build_*.py`。重新执行这些脚本可生成 SVG / JSON，再使用 `render_boards.cjs` 生成 PNG。
